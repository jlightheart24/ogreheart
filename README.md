# ogreheart

Website and portfolio for Ogreheart, a software development studio.

Plain HTML/CSS/JS — no build step.

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Edit

- Page text: `index.html`
- Portfolio projects: `js/projects.js`
- Colors and styles: `css/styles.css`
